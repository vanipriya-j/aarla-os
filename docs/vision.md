# Vision — Aarla OS

Aarla is a cultural lifestyle brand. Its objects — bottles, magnets, trays, books, brassware, totes — carry Worlds: Muruga, Lakshmi, Ganapathi, Chennai, Carnatic music, Bharatanatyam, Navarathri and more.

**Aarla OS** is the software expression of that brand for a single founder. It is not a generic ERP or another Shopify dashboard. It is a calm operating surface that holds the full arc of making:

> Idea → Story → Object → Vendor → Stock → Launch → Content → Order → Care → Review

## Principles

1. **One founder, many roles** — The product assumes the founder is strategist, buyer, packer, marketer and reviewer in a single day.
2. **Culture as operating logic** — Worlds and stories are first-class, not tags bolted onto SKUs.
3. **Warm software** — The interface should feel like Aarla became software: rooted, editorial, premium, human.
4. **Action over dashboards** — Home asks *what would you like to do today?* and opens working workflows, not dead links.
5. **Honest prototypes** — Version 0.1 is fully clickable with mock data. Integrations are simulated, never pretended to be live.

## Success for v0.1

- All ten primary tiles open complete screens
- Realistic Aarla mock data throughout
- Visual identity matches the brand palette and typography
- A founder can click through advice → idea → project → manufacture → receive → dispatch → launch → content → review without leaving the app
