# Product — Aarla OS v0.1

## Audience

A single founder operating Aarla day to day.

## Jobs to be done

| Job | Workflow |
|-----|----------|
| Get a clear recommendation grounded in stock & season | Need Advice |
| Expand a theme into product opportunities | Explore an Idea |
| Design institutional / gift hampers | Your Story. Our Telling. |
| Raise manufacturing or reorder POs | Manufacture / Reorder |
| QC and shelve inbound stock | Receive Stock |
| Pack and dispatch Shopify orders | Dispatch Orders |
| Prepare a product for launch | Launch Products |
| Plan multi-channel content | Content Studio |
| Track Worlds, clients and trips | Projects |
| See capital, revenue and movement | Business Dashboard |

## Home

- Question: **What would you like to do today?**
- **Ask Aarla** command bar
- Ten primary tiles
- Priorities, attention items, recent projects, pending orders, manufacturing updates, content tasks, revenue snapshot

## Non-goals (v0.1)

- Authentication
- Database / backend
- Paid services
- Live APIs
- Shopify / Delhivery / email / WhatsApp integrations

## Data posture

All data is local mock data in `src/lib/mock-data.ts`, typed in `src/lib/types.ts`.
