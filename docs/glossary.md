# Glossary

| Term | Meaning |
|------|---------|
| **World** | A cultural universe Aarla designs within (e.g. Muruga, Lakshmi, Chennai) |
| **Object** | A physical product category or SKU |
| **Story** | The narrative that binds a World to an Object or hamper |
| **Hamper** | A curated gift set for clients, events or institutions |
| **Opportunity** | A product concept from Explore an Idea, convertible to a Project |
| **Project** | An operating container for a launch, client job or sourcing trip |
| **PO** | Purchase / manufacturing order raised to a vendor |
| **Receive** | Guided inbound QC and shelving flow |
| **Dispatch** | Pack → label → courier handoff for channel / D2C orders |
| **Ask Aarla** | Founder copilot command bar / advice chat |
| **Content Studio** | Planning surface for posts, reels, picks and culture conversations |
| **Aarla Pick** | Curated recommendation content format |
| **Culture Conversation** | Editorial dialogue format rooted in cultural practice |
| **Capital blocked** | Inventory cost sitting unsold |
| **MOQ** | Minimum order quantity from a vendor |
| **Channel readiness** | Listing, barcode, photos and stock ready to sell on a commerce channel |
| **SalesOrder** | Canonical Aarla OS order — system of record for channel sales |
| **Commerce adapter** | Replaceable integration (e.g. Shopify) that maps into SalesOrders / catalog IDs; never owns inventory truth |
| **Channel pool** | Ledger location for D2C reserved stock (`loc-shopify`) — Aarla OS location, not a Shopify mirror |
